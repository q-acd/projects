info Как играть

Введите 2–4 слова (только русские буквы). Из их букв все по очереди составляют новые.

Лимит = n². После лимита — кнопка «Завершить».

Каждая буква = 5 монет.

touch_app Управление

🖱️ Перетаскивайте буквы, нажимайте, вводите с клавиатуры.

⌨️ Стрелки, Home/End, Backspace, Enter.

group Боты

В настройке игроков можно включить «Это бот» для любого игрока.

wifi Игра по сети

WebRTC через ручной обмен кодами. Работает в ~60–70% сетей без TURN-сервера.
